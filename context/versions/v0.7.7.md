# v0.7.7 · Guest mode & durable caps

**Date:** 16 Oct 2026 IST · **Branch:** p7-guest-caps

## Shipped
- Anonymous auth & Guest Mode:
  - `frontend/src/auth.ts`: `signInGuest()` using `signInAnonymously(auth)`.
  - `frontend/src/pages/NewBrief.tsx`: "Continue as guest" button with clean UX state.
  - `frontend/src/store.ts`: client-side persistent Zustand store for language & draft state.
  - `backend/app/auth.py`: `admin_principal` allows anonymous Firebase users; strict error handling returning generic 500 detail `auth verification failed` without leaking internal traces.
  - `backend/app/main.py`: allows anonymous owners on `/api/prebunk` and `/api/live/{session_id}` WebSocket (with strict session ownership isolation).
- Durable Rate Limiting & Abuse Protection:
  - Global anonymous daily cap enforced via Firestore `daily_stats` document (`prebunk_anon_daily_cap=100`).
  - Per-UID daily cap of 5 briefs for anonymous users.
  - XFF raw header logged; verified that spoofed `X-Forwarded-For` cannot bypass per-UID or global caps.
  - `firestore.rules`: client read/write strictly denied on `daily_stats`.
  - `firestore.indexes.json`: composite index for `sessions` (`is_anonymous` + `created_at`).
- Telegram Bot:
  - Commands `/start` and `/check` set via Bot API.
  - Help text updated to use `@ProofCardAgentBot`.
